# Snake Arena

Open index.html or serve the folder with python3 -m http.server 8000. All artwork is bundled. The lobby contains Russian settings for seven 2048×2048 terrain maps, personal flag, food colors, lighting, effects, bot population, evolution, minimap and labels. Game Studio also provides a game library and portable presets.

The entry is fixed at 5 and the exit opens at 25 collected units. Ordinary food pays 2.5 per unit and dropped food pays 0.5 per unit. Boost spends the current score. The language selects the displayed denomination (Portuguese BRL, English USD, Russian RUB). This is a display preference without exchange-rate conversion.

Steer with the joystick, pointer or arrow keys. Hold Space or the primary mouse button to boost. Escape pauses the game. W moves a funded snake to the exit for recording. Country flags come from flag-icons, with its license in assets/flags.
