# Snake Arena

Open index.html or serve the folder with python3 -m http.server 8000. All artwork is bundled. The lobby contains Russian settings for seven 4096×4096 terrain maps, personal flag, food colors, lighting, effects, bot population, evolution, minimap and labels. Game Studio also provides a game library and portable presets.

The entry is fixed at 5 and the exit opens at 25 collected units. Ordinary food pays 0.5 per unit. On death, the entire remaining score is divided among gold pieces to the cent. At round start, 94% of bots draw balances of 5–350 and 2% start above 1,000. Replacement bots usually enter with 0–25, with a 0.5% chance of 1,001–1,400. Boost costs 3 units per second. The language selects the displayed denomination (Portuguese BRL, English USD, Russian RUB). This is a display preference without exchange-rate conversion.

Steer with the joystick, pointer or arrow keys. Hold Space or the primary mouse button to boost. Escape pauses the game. W moves a funded snake to the exit for recording. Country flags come from flag-icons, with its license in assets/flags.
